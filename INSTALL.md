# Установка для агента

Цель: после одной ссылки подготовить рабочую папку, проверить PNG и объяснить маркетологу следующие действия. Выполняй шаги сам в доступном терминале; пользователя привлекай только там, где нужны его аккаунт или системное разрешение.

1. Клонируй `https://github.com/easylaneof/guru-skills.git` в отдельную папку. Если она уже существует, проверь её содержимое и origin; не затирай пользовательские файлы. Работай из корня клона. Прочитай `AGENTS.md`.
2. Проверь Git, Node.js >= 22 и npm. Если чего-то нет, определи ОС и доступный менеджер пакетов, помоги установить официальный runtime. Не меняй существующие проекты и глобальные конфиги агента.
3. Запусти `node setup.mjs`. Скрипт ставит фиксированные зависимости Remotion через `npm ci`, загружает Chrome Headless Shell, создаёт `.env` из примера только при его отсутствии, проверяет TypeScript, Node.js-тесты и рендерит три PNG. Повторный запуск сохраняет `.env`, фото и брифы. Ошибка любого шага означает, что установка ещё не завершена.
4. Открой PNG из `output/prochee/example/`. Проверь, что кириллица читается и элементы видимы во всех форматах. Геометрическая фигура — тестовый исходник; она намеренно не вызывает AI-генерацию.
5. Прочитай `.agents/skills/guru-photo-creatives/SKILL.md`. В Codex открой клон как проект: repo-local скилл обнаруживается в `.agents/skills/`. Если он не появился, перезапусти Codex. Не устанавливай отдельно одну папку скилла без остального репозитория: ему нужны helpers и remotion. В другом агенте явно читай SKILL.md перед работой.
6. Для наложения текста API-ключ не нужен. Если пользователь хочет генерировать фото, направь его на https://kie.ai/api-key: нужен собственный аккаунт с балансом. Открой локальный `.env`, чтобы пользователь сам вставил `KIE_AI_API_KEY`. Не проси ключ в чат, не выводи содержимое `.env`, не копируй чужие ключи. Не запускай платную генерацию как проверку установки.
7. Сообщи абсолютный путь рабочей папки, покажи три тестовых PNG и открой FIRST_RUN.md. Если пользователь просил провести его через первый креатив, продолжи по разделу «Инструкция агенту: как провести первый запуск» в этом файле. Объясни, что фото кладутся в `input/` или прикладываются к агенту, исходники для нейрогенерации отправляются Kie.ai, а готовые PNG сохраняются в `output/`.

Команды `node setup.mjs` и `node helpers/*.mjs` одинаковы для macOS, Linux и Windows. Python не требуется. Необходим агент с локальным терминалом; чат, умеющий только читать веб-страницы, установить зависимости не сможет.
