# Guru Skills

Набор скиллов Guru.AI для AI-агентов. Сейчас доступен `guru-photo-creatives` — создание рекламных фотокреативов.

Все скиллы в этом репозитории используют префикс `guru-`. Например, скилл для фотокреативов вызывается как `$guru-photo-creatives`. Новые скиллы добавляются с тем же префиксом.

Готовые рекламные фото для Яндекс Директа: берём исходную фотографию, при необходимости меняем образ через Nano Banana Pro (Kie.ai), накладываем русский текст существующим макетом Guru.AI и сохраняем PNG.

Работает через локального AI-агента с доступом к файлам и терминалу. Веб-сервис и сервер Guru.AI не нужны. Исходное фото можно передать **файлом PNG/JPG/WebP или прямой HTTP(S)-ссылкой**. Можно только наложить текст, без нейрогенерации и API-ключа.

## Что такое Kie.ai

[Kie.ai](https://kie.ai/market) — сторонний сервис, который даёт программам и AI-агентам доступ к нейросетям для создания изображений, видео и музыки через API — интерфейс для автоматических запросов.

В `guru-photo-creatives` через него работает [Nano Banana Pro](https://kie.ai/nano-banana-pro): агент отправляет исходное фото и описание нужных изменений, а сервис возвращает новое изображение. Например, так можно изменить фон или образ человека на фотографии.

Для этого нужны аккаунт Kie.ai, пополненный баланс и [API-ключ](https://kie.ai/api-key). Ключ — секретный код доступа к вашему аккаунту; он позволяет скрипту отправлять запросы от вашего имени. Генерации оплачиваются с баланса Kie.ai. Ключ сохраняется в локальном `.env`, передавать его в чат не нужно.

**Для наложения текста на готовое фото, изменения кадрирования и сборки трёх форматов Kie.ai не нужен.** Эти операции выполняются на вашем компьютере; начать можно с демо без ключа.

## Установка через агента

Передайте агенту этот запрос целиком:

> Установи https://github.com/easylaneof/guru-skills в отдельную локальную папку. Сначала прочитай INSTALL.md и AGENTS.md, выполни установку и проверку всех трёх форматов. Прочитай .agents/skills/guru-photo-creatives/SKILL.md. Проведи меня по FIRST_RUN.md: покажи демо в трёх форматах, затем помоги сделать креатив из моего фото. Начни без API-ключа и без платных генераций.

Агент установит Python-зависимости, Remotion и браузер для рендера. Если Python, Git или Node.js отсутствуют, поможет установить их для вашей ОС. Аккаунт Kie.ai и ключ создаёт владелец; агент не может получить их автоматически.

## Как пользоваться

Откройте папку репозитория в Codex. Скилл находится в `.agents/skills/guru-photo-creatives/`; его можно вызвать как `$guru-photo-creatives`. Другому агенту достаточно явно поручить прочитать этот файл.

Примеры запросов:

> Используй guru-photo-creatives. Возьми input/portrait.jpg, сделай один вариант фото этой же женщины с букетом роз. Затем наложи текст из пресета minuta и сохрани все три формата для Директа.

> Используй guru-photo-creatives. Возьми фото по ссылке https://example.com/photo.jpg, сохрани внешность, замени фон на осенний парк. Один вариант, пресет minuta, квадрат.

> Используй guru-photo-creatives. На готовое фото input/result.jpg наложи текст из пресета minuta. Нужны 1:1, 16:9 и 9:16. Само фото не перегенерируй.

> В готовом квадратном креативе уменьши заголовок до 80% и подними кадрирование, чтобы лицо не перекрывалось. Остальное оставь как есть.

Вместо пресета можно дать собственный точный текст. Агент не должен придумывать новые рекламные обещания. Исторические пресеты Guru.AI лежат в [COPY_PRESETS.md](COPY_PRESETS.md); перед рекламным запуском владелец проверяет соответствие текущему предложению.

## Что получается

- `1x1`: 1080 × 1080 PNG;
- `16x9`: 1920 × 1080 PNG;
- `9x16`: 1080 × 1920 PNG.

Сгенерированные фотографии: `remotion/public/assets/`. Рядом сохраняется JSON с промптом и данными генерации. Рабочие брифы: `briefs/`. Готовые креативы: `output/`; скрипт печатает фактический путь, например `output/prochee/portrait/minuta-1x1.png`. Эти папки и `.env` исключены из Git.

Установка создаёт примеры `output/prochee/example/minuta-1x1.png`, `minuta-16x9.png`, `minuta-9x16.png`. Геометрическая фигура в демо — техническая заглушка для проверки макета, не пример качества нейрогенерации.

## Ручные команды

Установка (macOS/Linux; на Windows используйте `py -3 setup.py`):

```bash
git clone https://github.com/easylaneof/guru-skills.git
cd guru-skills
python3 setup.py
```

Генерация из локального фото (платный запрос Kie.ai, ключ в `.env`):

```bash
.venv/bin/python helpers/generate_assets.py \
  --image-input input/portrait.jpg \
  --prompt "Same person as in the reference photo, preserve facial identity. Holding a bouquet of roses, soft daylight, photorealistic. No text or logos." \
  --name portrait-roses \
  --size 3:4
```

Для ссылки замените `input/portrait.jpg` на прямой URL изображения. Локальный файл загружается на сервер Kie.ai; ссылку Kie.ai скачивает самостоятельно. Генерации расходуют баланс Kie.ai. Исходники должны быть доступны провайдеру; защищённая страница облачного диска не является прямой ссылкой на фото.

Скопируйте `examples/poster-1x1.json` в `briefs/portrait-minuta-1x1.json`, замените `id` на `portrait-minuta-1x1` и `assets.after_image` на `assets/portrait-roses.png`. Для готового фото просто скопируйте его в `remotion/public/assets/` и укажите его имя в брифе.

```bash
.venv/bin/python helpers/render.py briefs/portrait-minuta-1x1.json
```

На Windows Python окружения находится в `.venv\Scripts\python.exe`. Все команды выполняются из корня репозитория. Схема брифа и проверка макета описаны в [скилле](.agents/skills/guru-photo-creatives/SKILL.md).

## Проверки и ограничения

```bash
.venv/bin/python -m unittest discover -s tests
npm --prefix remotion run lint
```

Установка и наложение текста не обращаются к платному API. Сетевое подключение нужно для установки пакетов, загрузки браузера и шрифтов Google Fonts. В тестах генератора используется поддельный HTTP-транспорт; реальные платные запросы в проверку установки не входят. Макет перенесён из рабочего пайплайна Guru.AI. Загрузка в рекламный кабинет, метрики и видео в эту поставку не включены.

Установка и три PNG проверены на macOS. Команды для Windows/Linux приведены, но отдельный прогон на этих ОС не выполнялся. В унаследованных зависимостях Remotion `npm audit` сообщает об уязвимостях (в текущем lock-файле: 24 high и 2 moderate). Не открывайте локальную Remotion Studio в публичную сеть; обновление зависимостей и повторная проверка макета остаются отдельной задачей.

Код сохранён со статусом исходного проекта `UNLICENSED`; публичность репозитория сама по себе не является открытой лицензией. У сторонних зависимостей свои лицензии.
