# Guru Skills

Это репозиторий скиллов Guru.AI. Сейчас в нём доступен guru-photo-creatives — инструмент для генерации рекламных фото и наложения текста. Работай из корня клона. Для установки читай INSTALL.md, для первого примера и онбординга — FIRST_RUN.md, для креативов — .agents/skills/guru-photo-creatives/SKILL.md.

- Все скиллы этого репозитория именуй с префиксом `guru-`: имя папки в `.agents/skills/` и поле `name` в `SKILL.md` должны совпадать, например `guru-photo-creatives`. Это правило действует и для новых скиллов. В инструкциях и примерах вызова используй полное имя с префиксом.
- Сохраняй макет PosterStill и согласованный текст. Новые обещания, цены и акции не придумывай.
- Ключ Kie.ai берётся только из локального .env или окружения. Не выводи его и не коммить.
- Пользовательские фотографии и брифы хранятся в игнорируемых папках input/, remotion/public/assets/, briefs/, output/.
- Генерация через Kie.ai платная. Установка не должна её запускать. При сбое сначала проверь taskId; не создавай повторную платную задачу автоматически.
- Результат всегда проверь визуально: лицо, кадрирование, читаемость, расположение текста. Сообщай фактические пути файлов.
- Разработка: Node.js-тесты `npm test`; TypeScript `npm --prefix remotion run lint`. Новую логику проверяй через подставной HTTP-транспорт и встроенный node:test, без реальных ключей и платных запросов.
