# Photo Creatives

Это самостоятельный инструмент для генерации рекламных фото и наложения текста. Работай из корня клона. Для установки читай INSTALL.md, для креативов — .agents/skills/photo-creatives/SKILL.md.

- Сохраняй макет PosterStill и согласованный текст. Новые обещания, цены и акции не придумывай.
- Ключ Kie.ai берётся только из локального .env или окружения. Не выводи его и не коммить.
- Пользовательские фотографии и брифы хранятся в игнорируемых папках input/, remotion/public/assets/, briefs/, output/.
- Генерация через Kie.ai платная. Установка не должна её запускать. При сбое сначала проверь taskId; не создавай повторную платную задачу автоматически.
- Результат всегда проверь визуально: лицо, кадрирование, читаемость, расположение текста. Сообщай фактические пути файлов.
- Разработка: Python-тесты `.venv/bin/python -m unittest discover -s tests`; TypeScript `npm --prefix remotion run lint`. Новую логику проверяй через httpx.MockTransport, без реальных ключей и платных запросов.
